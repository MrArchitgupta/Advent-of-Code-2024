# Advent of Code 2024

Solutions to Advent of Code 2024 challenges in C++.

## Solutions

- **Day 10 Part 1** - Recursive pathfinding with memoization to count unique endpoint paths
- **Day 14 Part 2** - Robot position simulation with collision detection and visual pattern recognition
- **Day 18 Part 2** - BFS pathfinding to find the blocking obstacle coordinate

## Compilation

```bash
g++ -o solution aocdXX_pY.cpp
```

## Running

Place input files as `inputXX.txt` in the working directory and run the executable.
